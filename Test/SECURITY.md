# Security — Nova Player

Nova Player plays local media and can optionally play network URLs. Your library stays local; there is no account or tracking. Automatic updates are disabled: users manually check for GitHub releases and confirm a SHA-256-verified setup download. The published Windows preview installer is unsigned. Do not disable Windows security software. Startup logs are stored locally at `%LOCALAPPDATA%\NovaPlayer\logs\startup.log` and may contain file paths; redact them before reporting issues.
