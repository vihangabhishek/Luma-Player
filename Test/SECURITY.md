# Security

- The app does not require accounts and does not intentionally collect telemetry.
- Your selected media file paths and playback positions are stored in `%APPDATA%\LumaPlayer\state.json`.
- Streaming URLs are sent to the remote server you choose. Never paste untrusted links.
- Local library state is **not encrypted**. Do not confuse it with Luma Diary encryption.
- This developer build is unsigned and has not had a professional security audit.
- Keep LibVLCSharp, VLC's native libraries and .NET patched as security fixes become available.
- Please report suspected vulnerabilities privately to the repository maintainer; do not post exploit details publicly.
- Distributing bundled LibVLC libraries imposes license obligations. Include third-party notices and comply with LGPL and applicable patent/codec licensing where relevant.
